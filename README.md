# Антон Юрков — Java Backend Engineer

Персональный статический сайт на русском языке: инженерные кейсы, подтверждённые результаты, опыт, технологии и контакты. Дизайн: графитово-синяя сдержанная палитра, без кислотных акцентов и декоративных «технологичных» эффектов.

## Что важно в контенте

- Кейсы структурированы как **контекст → моя работа → результат**.
- Для архитектуры billing явно указано участие **совместно с техническим лидом**.
- Цифры и технологии перенесены из резюме; вымышленных метрик, схем и секретных подробностей нет.
- Телефон, дата рождения и точный адрес не публикуются.
- Ключевые темы: границы сервисов, PL/SQL → Java, Oracle → PostgreSQL, платежи, Resilience4j, Testcontainers, OpenSpec, CI.

## Запуск

Откройте `index.html` в браузере. Всё работает без npm, сборки и сторонних скриптов. Для проверки URL вида `/index.html` можно также запустить `python3 -m http.server 8000` из директории проекта.

## Структура

- `index.html` — содержимое, SEO, социальные метатеги и семантическая разметка.
- `styles.css` — визуальная система, адаптивность и настройки доступности.
- `script.js` — навигация на мобильных, переключение кейсов, копирование email.
- `favicon.svg` — значок вкладки.
- `og-cover.png` — социальная обложка.

Согласовать формулировки инженерных кейсов, проверить контакты и решить, нужен ли публичный PDF с персональными данными. Если есть разрешённые к раскрытию диаграммы или ссылки на публичный код — добавить после проверки.
