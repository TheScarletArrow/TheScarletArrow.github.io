# Антон Юрков — Java Backend Engineer

Персональный статический сайт на русском языке: три раздела «Обо мне», «Опыт» и «Навыки», контакты в подвале. Дизайн: контрастная угольно-графитовая палитра с медно-терракотовыми акцентами и светлой карточкой ключевого результата, без кислотных акцентов и декоративных «технологичных» эффектов.

## Что важно в контенте

- У каждого из шести мест работы есть отдельные списки **обязанностей** и **достижений**. Три ранних места работы свёрнуты под «Ранний опыт». В Платформе ОФД есть подменю «Кейсы» с интеграциями Сбер Бизнес, ЮКасса и ФНС.
- Выполненная работа описана в прошедшем времени; общие навыки в разделе «Обо мне» — в настоящем.
- Для архитектуры billing явно указано участие **совместно с техническим лидом**.
- Автоматизация создания лицензий — цель billing-проекта в Платформе ОФД. Метрика «3 рабочих дня → менее минуты» обозначена как результат проекта; личный вклад описан отдельно. Самостоятельного кейса про лицензии нет.
- Цифры и технологии перенесены из резюме; вымышленных метрик, схем и секретных подробностей нет.
- Телефон, дата рождения и точный адрес не публикуются.
- Ключевые темы: границы сервисов, PL/SQL → Java, Oracle → PostgreSQL, платежи, Resilience4j, Testcontainers, OpenSpec, CI.

## Запуск

Откройте `index.html` в браузере. Всё работает без npm, сборки и сторонних скриптов. Для проверки URL вида `/index.html` можно также запустить `python3 -m http.server 8000` из директории проекта.

## Структура

- `index.html` — содержимое, SEO, социальные метатеги и семантическая разметка.
- `styles.css` — визуальная система, адаптивность и настройки доступности.
- `script.js` — навигация на мобильных, копирование email.
- `favicon.svg` — значок вкладки.
- `og-cover.png` — социальная обложка.
