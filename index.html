ПЛАТФОРМА ОФД / 2026BILLING · ARCHITECTURE

Разработка
billing-системы

Работал над billing-системой в Платформе ОФД. Цель проекта — автоматизировать создание пользовательских лицензий.

01 / КОНТЕКСТ

Пользовательские лицензии создавались специалистом БД вручную; процесс занимал до трёх рабочих дней. Billing-проект был направлен на автоматизацию этого процесса.

02 / МОЯ РАБОТА

Совместно с техническим лидом прорабатывал границы бизнес-доменов, структуру БД, взаимодействие сервисов и интеграции. Разрабатывал микросервисы, переносил логику из Oracle PL/SQL в Java и выпускал сервисы в production.

03 / РЕЗУЛЬТАТ ПРОЕКТА

Создание пользовательских лицензий автоматизировано: время выполнения сократилось с трёх рабочих дней до менее одной минуты.
